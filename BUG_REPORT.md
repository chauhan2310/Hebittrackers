# 🐛 Reporting Bugs

Found a bug? Thank you for helping improve Habit Tracker! Please follow this guide.

## Before Reporting

1. **Check existing issues** - Search to see if bug is already reported
2. **Update your browser** - Some issues are browser-specific
3. **Clear cache** - Clear browser cache and try again
4. **Test in private mode** - Disable extensions to isolate issues

## How to Report

### What to Include

- **Title** - Clear, concise description of the bug
- **Description** - Detailed explanation of what went wrong
- **Steps to Reproduce** - Step-by-step instructions to recreate
- **Expected Behavior** - What should happen
- **Actual Behavior** - What actually happened
- **Environment**:
  - Browser and version
  - Operating system
  - Device type (desktop/tablet/mobile)
  - Screen size/resolution
- **Screenshots/Videos** - Visual proof if applicable
- **Console Errors** - Any JavaScript errors (F12 > Console)

### Example Bug Report

```
Title: Checkboxes not persisting on page refresh

Description:
When I check off a habit for a specific day, the checkbox appears checked. However, 
when I refresh the page, the checkbox is unchecked again.

Steps to Reproduce:
1. Open Habit Tracker in Chrome
2. Click "Add Habit" and create "Test Habit"
3. Check the checkbox for today
4. Refresh the page (Ctrl+R)
5. Notice the checkbox is unchecked

Expected Behavior:
The checkbox should remain checked after page refresh

Actual Behavior:
The checkbox is unchecked after refresh

Environment:
- Browser: Chrome 90.0.4430.85
- OS: Windows 10
- Device: Desktop
- Screen: 1920x1080

Console Error:
Failed to load data from storage: SyntaxError: Unexpected token...
```

## Bug Severity Levels

### Critical 🔴
- App crashes or won't load
- Data loss
- Security vulnerability
- Feature completely broken

### High 🟠
- Major feature broken
- Significant performance issues
- Workaround not available

### Medium 🟡
- Feature partially broken
- Annoying but workaround exists
- UI/UX issue

### Low 🟢
- Minor UI glitch
- Cosmetic issue
- Nice-to-have fix

## Response Times

- **Critical**: 24 hours
- **High**: 48 hours
- **Medium**: 1 week
- **Low**: As available

## Follow-up

- You'll receive updates on your bug report
- We may ask for clarification or additional info
- Your report helps us improve the app!

## Security Issues

For security vulnerabilities, please email securely instead of opening a public issue. Contact the maintainer directly.
